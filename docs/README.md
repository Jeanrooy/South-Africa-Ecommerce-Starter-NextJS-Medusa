# Documentation

EcomStarter is a South African ecommerce template built on Medusa and Next.js. Form & Field is its replaceable demo brand.

| Guide                                           | Purpose                                                 |
| ----------------------------------------------- | ------------------------------------------------------- |
| [Setup](SETUP.md)                               | Install locally; configure environment, Peach and email |
| [Architecture](ARCHITECTURE.md)                 | Services, database ownership and request flows          |
| [Agent guide](AGENT-GUIDE.md)                   | Onboard coding agents and find implementation details   |
| [Storefront and builder](STOREFRONT-BUILDER.md) | Variations, content editing and limitations             |
| [Basket and checkout](BASKET-CHECKOUT.md)       | Shopping interactions and browser checks                |
| [Launch guide](LAUNCH.md)                       | Adapt and deploy a South African store                  |
| [Repository instructions](../AGENTS.md)         | Commands, conventions and protected paths               |

Agents should read repository instructions, architecture and the agent guide first. Installed package documentation describes the exact Medusa APIs. Public documentation may describe a newer version: compare examples with installed versions before applying them.

Screenshots in `images/` are curated local demo captures from ignored test artifacts. Refresh them when the UI changes. Use demo data and exclude customer information, credentials and tokens.
